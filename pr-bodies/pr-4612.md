## Summary

Fixes #4612 (stacked on #4611 / `feat/pedal-line-rend`).

1. Enable SMuFL `U+E656` (`keyboardPedalHalf`) in `fonts/supported.xml`, regenerate `smufl.h`, `smufl_names.inc`, and `Bravura_subset.woff2`, and return `U+E656` from `Pedal::GetPedalGlyph` for `dir="half"` (with fallback when unavailable).
2. Extend `PedalLineJoint` with `Step` and `Connected` transitions so `PreparePedalsFunctor` and `View::DrawPedalLine` render continuous half-depth stepped lines across `down`, `half`, `bounce`, and `up` sequences.
3. Add `MIDIBuilder::AddSustainPedalValue` (preserving the boolean `AddSustainPedal` overload) and emit `CC64 = 64` for `pedal@dir="half"`.
