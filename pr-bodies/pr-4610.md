## Summary

Fixes #4610.

1. Register `"pedline"` (`PEDALSTYLE_pedline`) in `Option::s_pedalStyle` so `--pedal-style pedline` and `{"pedalStyle": "pedline"}` are accepted.
2. Track active `<scoreDef>` and `<staffDef>` `@pedal.style` values in `PreparePedalsFunctor` (`VisitScoreOrPartElement`, `VisitScoreDef`, `VisitStaffDef`), store the resolved style in `Pedal::m_drawingPedalStyle`, and reset it in `ResetDataFunctor::VisitPedal`.
3. Replace `Pedal::GetPedalForm(doc, system)` with `Pedal::GetDrawingStyle()` across both `View::DrawPedal` and `View::DrawPedalLine` (and measure `pedal->GetPedalGlyph()`).
